# Проверки MapLink

```bash
npm install     # jsdom + postcss (только для разработки, в приложение не попадают)
npm run verify  # tg-режим, браузер-demo и браузер-без Telegram
```

Что именно проверяется — описано в шапке `verify.mjs`. Коротко: приложение
реально стартует в jsdom с заглушками CDN, payload'ы из базы не должны превращаться
в живые элементы, `getElementById` не должен ссылаться на несуществующие id,
read-only guard обязан резать запись вне Telegram и не мешать внутри.

`scan-xss.mjs` — статическая часть: проходит по инлайновому JS и находит вставки вида
`…${u.username}…` или `' + f.note + '` без обёртки в `esc()`. Именно она поймала снятый `esc()`
в списке друзей, когда DOM-проверка ещё молчала (экран не был открыт).

Отдельные режимы: `npm run verify:tg`, `verify:demo`, `verify:gate`
(и `node scan-xss.mjs index.html` — только сканер).

Приложение здесь не «тестируется как библиотека»: цель — за 5 секунд поймать
типичные для этого проекта поломки (удалил разметку, а код за неё цепляется;
забыл `esc()`; сломал синтаксис в 3000 строк JS).
